# פרויקט גיבוי אוטומטי – Bash Script + CRON Job

**שם התלמידה:** דינה גינזבורג
**תאריך:** 27.10.2026

## מבנה הפרויקט
```
project/
├── info.txt          # קובץ המידע לגיבוי
├── backup.sh         # סקריפט הגיבוי
└── backups/          # תיקיית הגיבויים (נוצרת אוטומטית)
```

---

## ✅ שלב 3 – הרשאות ריצה (לצורך ההגשה)
הפקודה שמוסיפה לסקריפט הרשאת ריצה (execute):

```bash
chmod +x backup.sh
```

---

## ✅ שלב 4 – הרצת הסקריפט ידנית
מתוך תיקיית `project`, יש להריץ:

```bash
./backup.sh
```

**נבדק בפועל ואומת בהצלחה:**
- ✔️ נוצרה תיקיית `backups`.
- ✔️ נוצר בתוכה קובץ בשם `info_2026-10-27_13-33.txt` (כולל תאריך ושעה בפורמט `YYYY-MM-DD_HH-MM`).
- ✔️ הקובץ נשמר בתיקיית `backups`.
- ✔️ על המסך הודפסה ההודעה:
  ```
  Backup completed successfully
  ```

בדיקה מהירה:
```bash
ls -l backups/
```

---

## ✅ CRON Job – שורת הפקודה (לצורך ההגשה)
יש ליצור CRON Job שמריץ את `backup.sh` כל שעה, ורק בימים ראשון עד חמישי.

פתיחת עריכת הקרונטאב:
```bash
crontab -e
```

**שורת הקרונטאב להוספה** (לעדכן את הנתיב המלא בהתאם למיקום בפועל של `project` במערכת):

```
0 * * * 0-4 /home/dina/project/backup.sh >> /home/dina/project/backup.log 2>&1
```

### הסבר השורה:
| שדה | ערך | משמעות |
|---|---|---|
| דקה | 0 | בדקה ה-0 של כל שעה |
| שעה | * | כל שעה |
| יום בחודש | * | כל יום |
| חודש | * | כל חודש |
| יום בשבוע | 0-4 | ראשון (0) עד חמישי (4) |

כך ה-CRON Job ירוץ בכל שעה עגולה (00 דקות), אך ורק בימים ראשון עד חמישי, ויכתוב את הפלט (כולל שגיאות) לקובץ `backup.log` לצורך מעקב.

---

## 📦 פריטי ההגשה
1. **`backup.sh`** – הסקריפט המלא.
2. **פקודת הרשאת הריצה:** `chmod +x backup.sh`
3. **שורת הקרונטאב:** `0 * * * 0-4 /home/dina/project/backup.sh >> /home/dina/project/backup.log 2>&1`


כך ה-CRON Job ירוץ בכל שעה עגולה, בימים ראשון עד חמישי בלבד, ויכתוב את הפלט (כולל שגיאות) לקובץ `backup.log`.
